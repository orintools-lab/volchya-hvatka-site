# План реализации «Волчья Хватка»

## Задачи на сегодня

- [ ] Поднять PostgreSQL, применить миграцию и seed — миграция готова, локальный
  запуск заблокирован отсутствием Docker в рабочей среде.
- [x] Завершить публичный лендинг с двумя комплектами.
- [x] Реализовать СДЭК: города, ПВЗ, курьер, расчёт и серверную перепроверку.
- [x] Реализовать заказ с размерами шашек, доставкой и серверным итогом.
- [x] Реализовать Робокассу: платёжная ссылка, ResultURL, success/fail и идемпотентность.
- [ ] Реализовать защищённую админку — готовы сессии, dashboard, товары, заказы,
  контент, отзывы, FAQ, платежи, CSV и логи; остаются файлы и расширенные настройки.
- [ ] Добавить обязательные тесты сквозного пути — готовы unit-проверки контракта
  заказа и подписи Робокассы; integration/E2E требуют PostgreSQL и credentials.
- [x] Проверить production-сборку и обновить Docker/README.

План следует этапам из раздела 21 технического задания. Каждый этап завершается
проверками `lint`, `typecheck` и тестами; найденные ошибки исправляются до перехода
к следующему этапу.
